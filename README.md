# FrameSlicer

This is an open-source project that allows you to slice video intervals into individual frames. It can be used for specific time intervals as well as for the entire video.

## Prerequisites

Supported versions [.NET](https://dotnet.microsoft.com/ru-ru/download/dotnet)
Library [FFMpegCore](https://github.com/rosenbjerg/FFMpegCore) 

## Installation

To use this project, you need to add the **FFMpegCore** library to your .NET application:

```bash
dotnet add package FFMpegCore
```
